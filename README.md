# 🎙️ Discord 通話時間制限・自動切断Bot

Discordのボイスチャンネルに通話時間制限を設け、指定時間が経過した際に参加者を自動切断するBotシステムです。
通話終了時には、通話時間と累計実績が専用テキストチャンネルに自動記録されます。

---

### 📋 主な機能

- **自動強制切断**
  設定時間（標準60分 / 1〜120分で指定可能）が経過すると、通話参加者をボイスチャンネルから自動切断します。実時間（タイムスタンプ）管理のため、Botの再起動等が発生しても正確に切断されます。
- **完全GUI操作対応**
  テキストチャンネルに常設できるコントロールパネル（`/panel`）を用意。スマホからボタンやメニューをタップするだけで、開始・延長・終了の全操作が完結します。
- **インラインリアルタイムモニター**
  通話中カードが自動更新され、プログレスバー・残り時間・切断予定時刻を表示。アラートもカード内で通知されるため、チャットログが流れません。
- **通話実績ログ（アルバム機能）**
  2人揃って通話した記録（通話時間・日時・今週および通算の累計実績）が専用チャンネルへ1枚のカードとして自動投稿されます。

---

### 📱 主な操作方法

#### コントロールパネル（推奨）
テキストチャンネルで `/panel` を実行すると操作パネルが常駐します。
- **▶️ 60分スタート**: ワンタップで60分タイマーを開始
- **⏱️ 時間を選択**: 15分〜120分、または手動入力（1分刻み）を選択して開始
- **➕ 10分延長**: 通話時間を10分延長（最大120分まで）
- **🛑 通話終了**: 通話を今すぐ終了してVCから切断
- **📊 状況確認**: 現在の残り時間を自分だけに表示

#### スラッシュコマンド
- `/panel` : 操作コントロールパネルを設置
- `/start [minutes]` : 指定した分数で通話開始（例: `/start minutes:45`）
- `/extend [minutes]` : 通話時間を延長（省略時は10分延長）
- `/cancel` : 通話タイマーを終了
- `/remaining` : 通話の残り時間を確認
- `/set_log_channel [channel]` : 通話記録の保存先チャンネルを指定
- `/stats` : 今週および通算の通話実績レポートを表示

---

### ⚙️ 必要なBot権限

Botには以下の権限が必要です（管理者権限は不要です）：
- **メンバーを移動 (`Move Members`)** ※自動切断に必須
- **チャンネルを見る (`View Channels`)**
- **メッセージを送信 (`Send Messages`)**
- **埋め込みリンク (`Embed Links`)**
- **メッセージ履歴を読む (`Read Message History`)**
