# 📞 恋人専用 Discord 通話自動切断Bot

恋人同士の長電話・夜更かしを防ぐため、Discordの2人専用ボイスチャンネルに制限時間を設け、指定時間が経過したら自動で強制切断するBotです。

---

## 🌟 主な機能
- **自動強制切断**: 指定時間（標準60分）が経過すると、通話中の2人をVCから自動切断。
- **実時間ベース・耐障害性**: SQLiteにタイマーを永続化。Botが再起動しても時間通りに切断。
- **スマホ最適化**:
  - スラッシュコマンド (`/start`, `/cancel`, `/remaining`, `/extend`, `/status`)
  - 開始通知に「残り時間」「15分延長」「タイマー中止」のインタラクティブボタンを装備。タップだけで操作可能。
  - Discord動的タイムスタンプ `<t:timestamp:R>` により、Discordアプリ上で「あと○分」がリアルタイム更新。
- **事前リマインド通知**: 終了5分前・1分前にテキストチャンネルへ予告通知。
- **自動クリーンアップ**: 2人が時間前に自発的に退出した場合はタイマーを自動終了。
- **誤切断防止**: タイマー開始時の通話参加者を記録し、第三者が混入しても意図しない切断を防止。
- **完全無料運用**: 自宅PC常時稼働、または無料クラウド（Koyeb、OCI Free Tier等）で運用可能。

---

## 🚀 クイックスタート (Windows)

1. `.env.example` をコピーして `.env` を作成します。
2. `.env` を開き、取得した `DISCORD_BOT_TOKEN` を入力します。
3. `start.bat` をダブルクリックして起動します。
